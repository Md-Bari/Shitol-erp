
  # ERP System

  This is a code bundle for ERP System. The original project is available at https://www.figma.com/design/7v7d1tznqpUNFwroMFZtXn/ERP-System.

## Running the frontend

Run `npm i` to install the dependencies.

Create `.env` from `.env.example`.

Run `npm run dev` to start the development server.

This frontend now expects a Laravel backend API at `/api` (proxied to `http://127.0.0.1:8000` via Vite).
